# AI Voice Assistant

A Python-based voice assistant that converts speech to text and text to speech. Ready for integration with calendar or note-taking features.

## Features
- Speech-to-text (SpeechRecognition)
- Text-to-speech (pyttsx3)
- Integration-ready for calendar/note-taking

## Setup
1. Create a virtual environment:
   ```bash
   python3 -m venv .venv
   source .venv/bin/activate
   ```
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the demo:
   ```bash
   python main.py
   ```
